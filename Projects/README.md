# Smartphone SQL Project

## Project Overview

This project demonstrates SQL analysis on a real-world smartphone dataset using MySQL Workbench.

The project covers:

- Database Creation
- Data Import
- Data Exploration
- Aggregate Functions
- Filtering
- GROUP BY
- ORDER BY
- Business Queries

Dataset Size:
- 758 Records
- 27 Columns
- 26 Smartphone Brands
